Engine Architecture & Task Pipeline

      
Separation of concerns between synchronous HTTP edge, message broker, and background workers.


      

        

          
1. FastAPI Dispatch

          
Pydantic v2 validation, Correlation ID injection, immediate 202 Accepted response.

        

        

          
2. Redis Broker

          
Multi-priority task queues (data_heavy, reports, media) with FIFO routing.

        

        

          
3. Celery Workers

          
Bounded concurrency (4x), late ACKs, prefetch control, and exponential retry backoff.

        

        

          
4. Persistent Backend

          
Redis key-value store holding state transitions, step progress, and final JSON payloads.
