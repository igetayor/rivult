        Rivult API Playbook & Route Reference
      

      

        

          

            POST
            /api/v1/tasks/aggregation
          

          

            Dispatches heavy data aggregation cube computation with anomaly detection to queue data_heavy.
          

        


        

          

            POST
            /api/v1/tasks/reports
          

          

            Compiles analytical executive PDF/CSV reports with stakeholder notifications to queue reports.
          

        


        

          

            POST
            /api/v1/tasks/image-pipeline
          

          

            Dispatches multi-stage media transformation batches to queue media.
          

        


        

          

            GET
            /api/v1/tasks/{task_id}
          

          

            Polls Redis persistent result backend for lifecycle stage, step metadata, and completion payloads.
          

        


        

          

            DELETE
            /api/v1/tasks/{task_id}
          

          

            Revokes and immediately terminates an active in-flight worker job via Celery control signals.
          

        


        

          

            GET
            /api/v1/metrics
          

          

            Returns real-time engine throughput statistics, dispatch counts, completion ratios, and server uptime.
